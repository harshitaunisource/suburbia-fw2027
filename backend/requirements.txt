# IMPORTANT: this project needs Python 3.12 (or 3.11) -- NOT 3.13/3.14.
# greenlet (a sqlalchemy dependency) and pydantic-core have no prebuilt
# wheels for 3.14 at the time this was written, so pip tries to compile
# them from source and fails with "Failed to build installable wheels".
# This has been the single most common recurring setup problem in this
# project. Before running `pip install -r requirements.txt`, always
# confirm your active venv reports Python 3.12.x or 3.11.x via
# `python --version` -- if it shows 3.13 or 3.14, stop and recreate the
# venv with `py -3.12 -m venv .venv` (see README.md's "Python version"
# section for the full, verified recipe).
